# Resume-Screening-and-Job-Matching-ML-PROJECT
Abstract

Resume Screening and Job Matching is a Machine Learning and Natural Language Processing project designed to automate the preliminary screening of resumes against specific job requirements. The system analyzes resume content and a given job description to identify relevant skills and information, helping recruiters efficiently find suitable candidates from a large pool of applicants.

The project uses spaCy Named Entity Recognition (NER) for extracting relevant information and skills from resumes. TF-IDF (Term Frequency–Inverse Document Frequency) is used to transform resume and job-description text into numerical feature representations, while Cosine Similarity measures the similarity between candidate resumes and the job description. Based on the calculated similarity scores, candidates are ranked according to their relevance to the specified job role.

The system also aims to provide insights into matched and missing skills, making the screening process more transparent and useful for recruiters. By combining NLP-based information extraction with similarity-based matching, the project demonstrates a practical application of Machine Learning in the recruitment domain and provides a foundation for developing an efficient, automated resume-screening system.
